# SITC public SEO and migration audit, 21 October 2026

## Scope and evidence

Read-only review of the public live site, sitemap XML, HTTP responses, rendered homepage in Edge, public WordPress content endpoints, and the local production build. Only homepage SEO code was changed after the user authorized that scope. No live deployment or submission was performed.

The crawl found 27 distinct public HTML URLs. All returned HTTP 200 and had a title, one H1, and a self-referencing canonical (normalizing percent-encoding for Sinhala paths). Public WordPress endpoints confirmed 11 published pages, 6 posts, and 5 programmes. Taxonomy archives account for the remaining 5 URLs. This is a public inventory, not a Search Console indexing or backlink report.

66 unique same-origin image/PDF URLs were checked with HTTP HEAD and all returned 200, including five course guides. This does not prove the contents or delivery of external services. Student portal returned 200; certificate verification redirected to `https://portal.sitc.lk/verify-certificate` and returned 200. HTTP and www variants redirect to `https://sitc.lk/`. An unknown live URL returned a genuine 404.

Full route inventory: [sitc-url-inventory-2026-10-21.csv](./sitc-url-inventory-2026-10-21.csv).

## Homepage changes implemented locally

- Preserve the live homepage title and description, Open Graph title/description/site name/locale/type/URL/image, and Twitter card/title/description/image in `src/content/seo.ts` and page metadata.
- Explicit homepage canonical `https://sitc.lk/` and index/follow/max-image-preview:large metadata.
- Canonical public identity is independent of local environment variables. Localhost and preview origins cannot enter homepage social or schema URLs.
- Homepage metadata is scoped to the page, rather than inherited by future routes or 404s. Shared layout retains only site-level defaults, icons, and theme colour.
- Public staging can set `PREVENT_INDEXING=true` at build time. Vercel previews receive `noindex, nofollow` automatically; the production build remains indexable. Canonicals stay on sitc.lk in both cases.
- Restore WebSite (including alternate name SITC), WebPage, and home breadcrumb entities, linked to the enriched EducationalOrganization and existing VideoObject. Stable legacy fragment IDs are retained. The original publication date is preserved; no invented modification date, SearchAction, ratings, or accreditation schema is added.
- Keep the visible trilingual wordmark as the organization's structured-data logo. Preserve the existing sharing image and Apple icon URLs under `/wp-content/uploads/`; those assets must survive launch.

Visible design, approved copy, programmes, and other route implementations are unchanged.

## Live sitemap and robots findings

- `https://sitc.lk/robots.txt` returns 200, generally allows crawling, blocks `/wp-admin/`, allows admin-ajax, and advertises `/sitemap.xml` and `/sitemap.rss`.
- `/sitemap.xml` is an AIOSEO sitemap index, returning 200.
- `/sitemap_index.xml` redirects with HTTP 302 to `/sitemap.xml`.
- Child counts: post 6, page 11, program 5, category 1, program_level 1. Total: 24.
- Three linked, indexable archives are absent from the sitemap: `/program-level/undergraduate/`, `/program-level/specialized-masters/`, `/program-level/ph-d/`.
- Diploma and uncategorized archive sitemap dates are 1970-01-01. Replace with accurate significant modification dates or omit unknown dates.
- The sitemap's own `X-Robots-Tag: noindex, follow` is not a page-indexing failure. It applies to the XML document.
- Local `/robots.txt` and `/sitemap.xml` still return 404. Their migration is deferred until the handling of the remaining live routes is decided. Do not replace the site's complete sitemap with a homepage-only list during a partial rollout.

## Issues and dependencies to decide later

- All five live course pages lack a meta description. The uncategorized archive also has none. Preserve useful SEO fields, but fill these gaps rather than copying omissions.
- Undergraduate, master's, and PhD archives have a February 2026 intake notice and no listed course cards in the crawled HTML. Several course pages still advertise 2025 intakes. Verify approved current dates, course titles, qualifications, fees, and guides before migration.
- Local programme records contain 10 offerings (6 diploma and 4 degree); the public live catalogue lists 5 diploma programmes. This is a discrepancy for owner review, not authorization to remove or invent programmes.
- The new homepage does not reproduce all existing homepage content: campus introduction, news, testimonials, partners/recognitions, events, and statistics require a content-preservation decision. CodeZela career-accelerator content also exists in the fetched homepage source, although it was not visible in the tested desktop view.
- The live contact page has a POST feedback form. The local enquiry form opens a WhatsApp compose window. They serve different functions; contact delivery/backend must be preserved or deliberately replaced. No form was submitted during audit.
- Current full-site search uses WordPress/JetSearch. The local filter searches the local programme list only.
- Contact-page appointment buttons currently link back to `/contact-us/`. A decorative Lottie link points to `https://sample.com`; this is separate from those buttons.
- Public source includes Google tag `GT-TQDTMCJ` and Meta pixel `1036886727055370`. The local project does not install those tags. Confirm their destinations, consent requirements, and conversion events before moving tracking. Public IDs alone do not prove analytics delivery.
- Keep portal/verification subdomains, DNS verification, mail records, old PDFs/image paths, feeds, Unicode URLs, query parameters, and ad landing URLs working. Existing footer links to sitc.lk paths will become local missing routes if the entire domain is replaced with this one-page build.
- The Vice Chancellor language tabs do not create separate language URLs. If full multilingual search targeting is wanted, plan translated pages and reciprocal hreflang rather than adding hreflang for nonexistent pages.
- Homepage video schema does not guarantee video search eligibility. A decorative hero is not a dedicated watch page.

## Migration gates

For a homepage-first rollout, retain WordPress on other paths and test routing for the new homepage, its assets, and the existing site's assets/APIs. For a complete replacement, first rebuild required pages on their existing paths or create a reviewed redirect map. Do not redirect unrelated old pages to the homepage.

Keep HTTPS/non-www normalization, real 404s, canonical tags, robots access, and the full site's sitemap consistent. Protect public staging from indexing. Before launch, export Search Console pages/queries/indexing/sitemaps and analytics landing/conversion data to identify URLs not exposed by this public crawl. Verify DNS ownership and maintain a rollback backup. After launch, inspect the public HTML and status codes, validate structured data, submit the correct sitemap, and monitor indexing, 404s, traffic, and conversions.

PageSpeed API returned HTTP 429 (quota exhausted), so no performance score or Core Web Vitals pass is claimed. Search Console, authenticated analytics, server logs, historical redirects/backlinks, and actual form delivery were not inspected. Rankings cannot be guaranteed by metadata parity alone.
